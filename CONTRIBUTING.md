# Contributing

This portfolio project welcomes focused improvements that strengthen credit risk modeling, governance, reproducibility, or dashboard storytelling.

## Good Contributions

- additional model monitoring SQL,
- fairness diagnostics,
- improved dashboard screenshots,
- alternative calibrated model challengers,
- deployment hardening,
- documentation that clarifies business tradeoffs.

## Development Workflow

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pip install -e .
pytest
```

Keep changes scoped and include validation notes in the pull request.
